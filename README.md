# Ad Pilot: AI-Powered Ad Campaign Management

Ad Pilot is a comprehensive SaaS platform built with Next.js and TypeScript, designed to help users manage, analyze, and optimize their Meta (Facebook & Instagram) advertising campaigns. It leverages the power of Google's Gemini AI to provide actionable insights, budget recommendations, and performance analysis. The application features separate dashboards for users and administrators, a subscription-based model, and a full suite of tools for monitoring ad performance.

## Features

### User-Facing Platform
- **Public Site:** A landing page with sections for Features, Services, Pricing, and a Contact form.
- **Authentication:** Secure user registration and login.
- **Subscription Tiers:** A 'Free' tier with limited features and a 'Pro' tier with full access, managed via Stripe checkout.

### User Dashboard
- **Performance Overview:** A central dashboard displaying key metrics like Total Spend, Impressions, Clicks, and ROAS with analytical charts.
- **Campaign Management:** View a filterable and searchable list of all synced Meta ad campaigns.
- **AI-Powered Insights:** (Pro Feature) Select any campaign to receive a detailed performance analysis and optimization recommendations generated by the Gemini AI.
- **Settings:**
    - **Integrations:** Connect and manage Meta Business and Instagram Professional accounts.
    - **Preferences:** Switch between Light, Dark, and System themes.
    - **Billing:** View current subscription plan and manage billing.
- **Profile Management:** Update personal information and change account passwords.

### Admin Panel
- **System Analytics:** An overview dashboard tracking key platform metrics like Monthly Recurring Revenue (MRR), total users, Pro vs. Free user counts, and Meta connection rates.
- **User Management:** Search, filter, and manage all registered users. Admins can manually upgrade or downgrade user subscription plans.
- **Subscription Monitoring:** A dedicated view to monitor all active, past due, and canceled subscriptions, with direct links to the Stripe dashboard for each customer.
- **Admin Profile:** Secure section for administrators to manage their own profile and password.

## Getting Started

To run this project locally, you will need to have Node.js and a package manager (npm, yarn, or pnpm) installed. This project serves as the frontend and requires a separate backend API to function correctly.

### Prerequisites

- Node.js (v20 or later recommended)
- npm, yarn, or pnpm
- A running instance of the corresponding backend API.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Sehar-1207/ad_pilot.git
    cd ad_pilot
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Set up environment variables:**

    Create a `.env.local` file in the root of the project and add the URL of your backend API server.

    ```env
    NEXT_PUBLIC_API_URL=http://localhost:5000/api
    ```

4.  **Run the development server:**
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
